# 1002 variable mutated but never accessed

Severity: medium · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 1002`.

## What it means

A local variable that is assigned (or declared and then assigned) multiple times
but is never read. luacheck reports this as `241` (variable mutated but never
accessed).

A single assignment that is never read is `999`; this code fires only when the
variable has more than one definition, i.e. it was written again after its
first assignment without any read in between.

A `local function` is not reported: the function may be returned, passed as a
callback, or called indirectly, so the static walk cannot prove it is dead.

## Example

```lua
local function f()
   local x
   x = 1
end
return 2
```

## How to fix

Read the value where it is needed, or remove the variable and its assignments if
they are dead code.

```lua
local function f()
   local x
   x = 1
   return x
end
return f()
```

## Fix prompt

```prompt

```
