# 961 comparing with a table constructor

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

A comparison has a table constructor on one side. selene reports this as
`constant_table_comparison`. A table literal is a new value each time it is
evaluated, so it is never identical to anything else; `==` against one is always
false and `~=` is always true. Comparing a variable that holds a table is not
reported — the check is for the constructor literal.

## Example

```lua
if x == {} then end
```

## How to fix

Compare a field of the table, or store it in a variable first and compare the
variable, depending on what the intent was.
