# 1004 copy loop into an empty table: a manual table.clone

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 100`.

## What it means

A new empty table is filled, at once, by a loop that copies every entry of
another local table one key and value at a time. `table.clone` does the same copy
in one call, and is easier to read. selene reports this as `manual_table_clone`.

The lint matches only the exact shape: `local out = {}`, then directly after it
`for k, v in pairs(src) do out[k] = v end`, where `src` is a local, and the loop
body is that one assignment. `ipairs` is not matched, because `table.clone`
copies every key while `ipairs` copies only the array part.

`table.clone` exists in Luau (Roblox), not in Lua 5.1 to 5.4 or LuaJIT. On those
dialects the fix is a helper, not `table.clone`.

## Example

```lua
local src = {1, 2}
local out = {}
for k, v in pairs(src) do out[k] = v end
```

## How to fix

Write `local out = table.clone(src)` where the dialect has `table.clone`. Elsewhere,
keep the loop: it is correct, and the finding only says a clone helper would read
better.
