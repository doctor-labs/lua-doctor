# 969 unbalanced assignment

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

A `local` or plain assignment has a different number of names on the left and values on the right, and the last value cannot expand to fill the gap. luacheck reports these as 531 (more names than values) and 532 (more values than names); selene as `unbalanced_assignments`. A trailing function call, method call, or `...` can supply any number of values, so an assignment whose last value is one of those is not reported (`local a, b = f()`, `local c, d = ...`).

## Example

```lua
local a, b = 1
x, y = 1, 2, 3
```

## How to fix

Make the name and value counts match. Add or remove a name or value, or rely on a trailing call or `...` to expand.

## Fix prompt

```prompt
lua-doctor reported 969 (unbalanced assignment) at {file}:{line}. Fix the assignment so the number of names matches the number of values (a trailing call or `...` can expand to any count), keeping behaviour the same otherwise, and re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
