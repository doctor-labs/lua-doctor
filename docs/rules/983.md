# 983 unused function argument

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 98`.

## What it means

A named function parameter that is never read in the body. luacheck reports
this as `212`.

The vararg parameter `...` and the implicit `self` of a colon-method
(`function M:run(...)`) are never flagged: they are not named parameters in the
luacheck sense, and `self` has no source position of its own.

## Example

```lua
local function f(used, unused_name)
   return used
end
return f(1, 2)
-- std lua51
```

## How to fix

Use the parameter where it is needed, rename it to `_` by convention if it is
intentionally unused, or remove it from the signature.

```lua
local function f(a, b)
   return a + b
end
return f(1, 2)
```
