# 989 value of argument is overwritten before use

Severity: high · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 989`.

## What it means

A function argument is reassigned before it is ever read, so the original
argument value can never be observed. luacheck reports this as `312`.

## Example

```lua
local function f(a)
  a = 2
  return a
end
```

The incoming value of `a` is lost — the parameter is overwritten before any
read.

## How to fix

Use a local variable instead of reassigning the parameter, or remove the
dead reassignment:

```lua
local function f(a)
  local x = a or 2
  return x
end
```
