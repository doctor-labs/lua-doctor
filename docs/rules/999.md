# 999 unused local

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 999`.

## What it means

A `local` variable that is bound but never read in its scope. luacheck reports
this as `211` (a local with a single unused definition) or `231` (assigned but
accessed nowhere).

A `local function` is not reported: the function may be returned, passed as a
callback, or called indirectly, so the static walk cannot prove it is dead.

The throwaway name `_` is not flagged.

## Example

```lua
local function f()
   local x = 1
end
return 2
```

## Fix prompt

```prompt
lua-doctor reported 999 (unused local) at {file}:{line}: {msg}. The local variable `{name}` is bound in this scope but never read. Either reference it where its value is needed, or remove the declaration if it is dead code. Re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
