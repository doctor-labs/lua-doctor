# 984 unused loop variable

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 98`.

## What it means

A loop variable that is never read in the loop body. luacheck reports this as
`213`.

Two kinds of loop variable are covered:

- The key/value pair of a generic `for k, v in pairs(t) do ... end`.
- The counter of a numeric `for i = 1, n do ... end`.

A name that is exactly `_` is the conventional throwaway and is not flagged.

## Example

```lua
local t = {}
for i, v in ipairs(t) do
   t[#t + 1] = i
end
return t
-- std lua51
```

## How to fix

Use the variable in the loop body, rename it to `_` if it is intentionally
unused, or remove it from the loop.

```lua
local t = {}
for i, v in ipairs(t) do
   t[#t + 1] = i + v
end
return t
```
