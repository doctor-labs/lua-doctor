# 972 division by literal zero

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

A `/` or `%` whose right operand is the literal number `0`, or folds to `0` at compile time, causes a division by zero at run time and raises a Lua error: `attempt to divide by zero`. selene reports these as `divide_by_zero`.

The NaN idiom `0/0` — where both operands are the literal `0` — is not reported: it is the standard way to produce a NaN value, not a division-by-zero mistake.

## Example

```lua
local a = x / 0
local b = y % 0
```

## How to fix

Guard the divisor with a non-zero check (`if denom ~= 0 then ... end`), use a default value (`x / (denom ~= 0 and denom or 1)`), or restructure the computation so zero is never a divisor.
