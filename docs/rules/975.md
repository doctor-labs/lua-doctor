# 975 multiple statements on one line

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

More than one statement begins on the same line, within a single block. A single
statement that happens to span multiple lines, or a compound statement whose
nested block sits on the same line (e.g. `if a then return end`), is one
statement in its block and is not reported. selene reports this as
`multiple_statements`.

## Example

```lua
local a = 1; local b = 2
```

## How to fix

Place each statement on its own line:

```lua
local a = 1
local b = 2
```

## Fix prompt

```prompt
lua-doctor reported 975 (multiple statements on one line) at {file}:{line}. Two or more statements start on the same line; split them onto separate lines, keeping behaviour the same otherwise, and re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
