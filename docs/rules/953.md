# 953 setting a read-only global variable

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

The code assigns a global that the Lua standard defines as read-only (`os = nil`, `print = f`) or assigns a field of one (`string.format = f`, `os.execute = g`). luacheck reports these as 121 and 122. Replacing a standard function is rarely an accident: it is how a script wraps, hooks or silently swaps `os.execute` or `io.popen`, and any later call through the new function is invisible to a scanner that matches on the standard name.

## Example

```lua
string.format = function() return "" end
```

## How to fix

Do not overwrite the standard library. Wrap the call in a function of your own and call that, or, in a sandbox, hand the script a fresh environment table instead of changing the real one.
