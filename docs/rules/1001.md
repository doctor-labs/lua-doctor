# 1001 unused loop variable

Severity: high · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 1001`.

## What it means

A loop variable that is never read in the loop body. luacheck reports this as
`213` (unused loop variable) or `233` (loop variable never accessed).

Two kinds of loop variable are covered:

- The key/value pair of a generic `for k, v in pairs(t) do ... end`.
- The counter of a numeric `for i = 1, n do ... end`.

A name that is exactly `_` is the conventional throwaway and is not flagged.

## Example

```lua
for i = 1, 3 do
   print(j)
end
```

## How to fix

Use the loop variable in the body, or replace the name with `_` to signal that
the value is intentionally unused.

```lua
for i = 1, 3 do
   print(i)
end
```

## Fix prompt

```prompt
lua-doctor reported 1001 (unused loop variable) at {file}:{line}: {msg}. The loop variable `{name}` is never read in the loop body. Either reference it where its value is needed, or replace its name with `_` to mark it intentionally unused. Re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
