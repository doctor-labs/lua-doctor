# 982 unused local

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 98`.

## What it means

A `local` — including a `local function` — that is bound but never read anywhere
in its scope. luacheck reports this as `211`.

A call to a local function counts as a read: `local function f() end; f()` is
not reported. Reading the name through `_G` (e.g. `_G.f()`) counts as a read of
the local only when the local is explicitly referenced; an indirect lookup via
`_G` does not.

## Example

```lua
local unused = 1
return 2
-- std lua51
```

## How to fix

Read the value where it is needed, or remove the binding if it is dead code.

```lua
local used = 1
return used
```

## Fix prompt

```prompt

Either reference it where its value is needed, or remove the declaration if it is dead code. Re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
