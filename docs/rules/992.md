# 992 value assigned is never accessed

Severity: high · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 992`.

## What it means

A local variable is assigned a value and never read. Depending on the
pattern, luacheck reports this as either:

- `231` — the variable is assigned but never accessed at all, or
- `331` — the variable is assigned, then mutated (reassigned) but never read.

Both map to this rule because the value can never escape use.

## Example

```lua
local function f()
  local x = 1
  x = 2
end
```

`x` is assigned and reassigned, but never read — both values are dead.

## How to fix

Remove the unused variable, or add the read that was intended:

```lua
local function f()
  local x = 1
  return x
end
```

## Fix prompt

```prompt

Re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
