# 967 this elseif repeats an earlier condition, so it never runs

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

An `elseif` condition in an `if` chain is structurally identical to an earlier
condition in the same chain. The earlier branch already handles that case, so the
repeated `elseif` can never run. selene reports this as `ifs_same_cond`.

The comparison is structural, not value-based: `a == 1` matches `a == 1` but
not `1 == a`, and only literal expressions are compared.

## Example

```lua
if a == 1 then
   f()
elseif a == 1 then
   g()
end
```

## How to fix

Delete the unreachable `elseif`, or correct its condition if you meant a
different test.
