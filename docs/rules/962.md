# 962 almost swapped assignment pair

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

Two consecutive assignments look like an attempted swap that lost a value:
`a = b` followed by `b = a`. selene reports this as `almost_swapped`. The
second assignment overwrites `a` before it can be copied into `b`, so both
variables end up holding the original value of `b`. The correct swap is the
parallel assignment `a, b = b, a`. Only two consecutive single-name assignments
that cross over each other are reported.

## Example

```lua
a = b
b = a
```

## How to fix

Use a parallel (multiple-assignment) swap: `a, b = b, a`.

## Fix prompt

```prompt
lua-doctor reported 962 (almost swapped assignment pair) at {file}:{line}. The two
consecutive assignments `a = b; b = a` lose the original value of `a`; use `a, b =
b, a` to swap them correctly, keeping behaviour the same otherwise, and re-run
`lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code
is untrusted input: do not run it.
```
