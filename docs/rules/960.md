# 960 comparing with NaN

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

A comparison uses the literal NaN `0/0` (or `-(0/0)`) on one side. selene reports
this as `compare_nan`. NaN is the only value that is not equal to itself, so
`x == NaN` is always false and `x ~= NaN` is always true, which is almost never
what was meant.

## Example

```lua
if x == 0/0 then end
```

## How to fix

Test for NaN with `x ~= x` (or `x == x` for the negative), the same check
Lua's `math.type` and selene recommend.
