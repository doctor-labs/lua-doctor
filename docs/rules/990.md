# 990 value of loop variable is overwritten before use

Severity: high · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 990`.

## What it means

A loop variable (numeric `for` counter or generic `for` key/value) is
reassigned inside the loop body before it is read, so the loop-provided value
is lost. luacheck reports this as `313`.

## Example

```lua
for i = 1, 3 do
  i = 2
  print(i)
end
```

The value of `i` that the `for` assigns each iteration is overwritten before
it can be read.

## How to fix

Iterate over a copy if you need a mutable counter, or use a separate variable:

```lua
for i = 1, 3 do
  local n = 2
  print(n)
end
```

