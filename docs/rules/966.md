# 966 two branches of this if do the same thing

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

Two branches of one `if` / `elseif` / `else` chain have structurally identical,
non-empty blocks. One of them is dead: whichever condition came first wins the
tie. selene reports this as `if_same_then_else`.

Empty branches are not reported here; they are a separate selene check
(`empty_if_conditions`) and out of lua-doctor's range.

## Example

```lua
if x then
   do_thing()
else
   do_thing()
end
```

## How to fix

Remove the duplicate branch, or make the branches differ. If one branch is meant
to be the catch-all, make sure the earlier branch's condition is not a superset
of what you intended.

## Fix prompt

```prompt
lua-doctor reported 966 (two branches of this if do the same thing) at {file}:{line}. Fold the two identical branches into one or give them different bodies so each branch does something distinct, keeping behaviour the same otherwise, and re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
