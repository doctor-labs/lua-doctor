# 950 deprecated standard function

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`, and only when a Lua standard is named with `--std` (for example `--std lua52`). With no standard named, the union of all standards is in effect and nothing is judged deprecated.

## What it means

The named Lua standard still defines the function, but a later Lua version deprecated it, so it is best replaced now. selene reports the same thing as `deprecated`.

Today this covers the lua52 standard only: Lua 5.3 deprecated `math.atan2`, `math.cosh`, `math.frexp`, `math.ldexp`, `math.pow`, `math.sinh` and `math.tanh`, and dropped them from its default build. Functions that Lua 5.2 already removed (`loadstring`, `unpack`, `setfenv`) are absent from the lua52 standard, so calling them is reported as 903 (API not in the configured standard) instead.

The compatibility standard `lua52c` is not judged: it keeps these functions on purpose.

## Example

With `--std lua52`:

```lua
local power = math.pow(base, exp)
```

## How to fix

Use the replacement the message names, `x ^ y` for `math.pow`, for example, or write the formula another way when the message names none.

## Fix prompt

```prompt
lua-doctor reported 950 (deprecated standard function) at {file}:{line}. Replace the call with the replacement the message names, keeping the result the same, and re-run `lua-doctor --category lint --std lua52 {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
