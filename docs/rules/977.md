# 977 indentation has a space before a tab

Severity: low · Confidence: high · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

The leading whitespace of a line contains a space immediately followed by a tab
(for example `" \t"`). Mixing spaces and tabs in indentation is inconsistent and
renders differently depending on tab stops, so luacheck (code 621) and
lua-doctor flag it as a single style issue, 977.

luacheck reports this at the start of the leading whitespace run. lua-doctor
skips pure-whitespace lines — those are 976's concern — and skips lines that
continue a multi-line string (`line_endings[line - 1] == "string"`), because
their leading spaces are part of the string value rather than indentation.

## Example

The body line is indented with a space followed by a tab, then the statement:

```lua
if x then
	print(x)
 	print(x)
end
```

`--std lua51`

## How to fix

Pick one indentation style and make every leading-whitespace run use only that
kind: either spaces or tabs, not both. Expand the tab to spaces, or replace the
space with a tab, so the leading run is uniform.

## Fix prompt

```prompt
lua-doctor reported 977 (indentation has a space before a tab) at {file}:{line}. The line's leading whitespace mixes a space and a tab. Rewrite the indentation using spaces only or tabs only — expand the tab to spaces or replace the leading space with a tab — so the leading run is uniform, keeping the statement otherwise unchanged, and re-run `lua-doctor --category lint {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
