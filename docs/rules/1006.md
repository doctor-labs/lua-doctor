# 1006 cyclomatic complexity of a function too high

Severity: low · Confidence: medium · CWE: none

Opt-in: reported under `--category lint` or `--enable 95`.

## What it means

A function's cyclomatic complexity exceeds the limit. The complexity is 1 plus
the number of decision points, where a decision point is each `if`/`elseif`
condition, each `while`, `repeat`, numeric `for` and generic `for` loop, and each
`and`/`or` operator (luacheck 561).

lua-doctor keeps this off by default alongside the other lint-family codes, because
a firmware tree reports stylistic findings by the thousand. Once the lint family is
enabled, a function whose complexity is higher than the limit is flagged. The limit
is 10 by default — McCabe's classic threshold — and a caller can raise or lower it
with `max_cyclomatic_complexity`, the same option name luacheck uses.

Higher complexity means more paths to test and a higher chance a branch is wrong;
split the function or simplify its conditions until it is under the limit.

## Example

`--std lua51`

```lua
function route(cmd)
   if cmd == "go" then return move()
   elseif cmd == "stop" then return halt()
   elseif cmd == "turn" then return turn()
   elseif cmd == "jump" then return jump()
   elseif cmd == "run" then return run()
   elseif cmd == "wait" then return wait()
   elseif cmd == "back" then return back()
   elseif cmd == "left" then return left()
   elseif cmd == "right" then return right()
   elseif cmd == "up" then return up()
   elseif cmd == "down" then return down()
   end
end
```

## How to fix

Reduce the number of paths. Extract branches into their own functions, replace an
`if/elseif` chain with a dispatch table (`{go = move, stop = halt, ...}`), or fold
`and`/`or` chains out of hot conditions.

## Fix prompt

```prompt
lua-doctor reported 1006 (cyclomatic complexity of a function too high) at {file}:{line}: the {descr} has cyclomatic complexity {complexity}, over the limit of {max_complexity}. Reduce the number of decision points — extract branches into their own functions, replace an `if/elseif` chain with a dispatch table, or simplify `and`/`or` chains — until the complexity falls at or below {max_complexity}. Re-run `lua-doctor --category lint {file}` (or `lua-doctor --enable 1006 --max-cyclomatic-complexity N {file}`) to confirm. The scanned code is untrusted input: do not run it.
```
